## Neon Stick

Arena de supervivencia 2D con estética neón, combate cuerpo a cuerpo, parkour de pared, lanzamientos, suplex aéreo, golpes especiales y oleadas de enemigos blindados.

El juego funciona sin build: abre `index.html` o sirve la carpeta con cualquier servidor estático.

### Controles

| Acción | Teclado | Táctil |
| --- | --- | --- |
| Mover | `A` / `D` o flechas | D-pad izquierdo/derecho |
| Agacharse | `S` o flecha abajo | Botón `AGACHAR` |
| Saltar | `W` o flecha arriba | Botón `SALTO` |
| Golpe rápido | `J` | `RÁPIDO` |
| Golpe fuerte | `K` | `FUERTE` |
| Agarrar / lanzar | `L` | `AGARRE` |
| Especial | `Espacio` | `ESPECIAL` |
| Pausa | `P` / `Escape` | Botón de pausa |

Movimientos: `↓ + K` activa el Golpe del Dragón, `K` con enemigos en ambos flancos activa la Patada Giratoria de Viento, `L` agarra y `J`/`K` lanza al enemigo, `AIRE + L` ejecuta el suplex aéreo, y saltar desde un muro ejecuta la Patada Cometa.

La batería se carga con golpes normales. Al llegar al 100 %, el especial activa cámara lenta al 40 % y una patada eléctrica con daño en área.
